## 🚀 Execution Order & Commands

### Step 1: Environment Setup
```bash
# Run once to setup everything
python setup_environment.py --install-deps --create-structure
```

### Step 2: Dataset Preparation
```bash
# Consolidate your existing PNG/JSON files into CSV
python scripts/data_consolidator.py captcha_dataset --output-dir .
```

### Step 3: Training (GPU Recommended)
```bash
# Train models with GPU acceleration
python scripts/batch_trainer.py --use-gpu --epochs 50
```

### Step 4: Testing & Validation
```bash
# Comprehensive testing
python test_framework.py --test-type all --save-results
```

### Step 5: Integration with Phase 1
```bash
# Test integration
python scripts/captcha_integration.py path/to/test_captcha.png
```
